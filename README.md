# Avalon 大众点评免费试 自动报名

## 开启方法
1. 在设置页面中搜索无障碍，点击 辅助功能 -> 无障碍
2. 选择已下载的应用，并在应用列表中找到 HaKu免费抽服务【后续填充其他功能可能会换名】
3. 开启快捷启用功能，不同Android系统适配效果可能不一样，也可以主动点击开启

## 使用方法
1. 进入大众点评APP，打开免费试页面
2. 开启本服务，有快捷启用按钮的，直接点击快捷按钮即可
3. 触摸下屏幕，触发事件开始即可
